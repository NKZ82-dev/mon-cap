Comment ça fonctionne

1L’extension relèveSur votre ordinateur, elle se connecte au portail Coba avec vos identifiants, lit Classroom dans la vue tuteur, et lit les résumés Classroom de votre Gmail.
2Le relais rangeUne feuille Google copiée dans votre compte contient un petit programme. Il dépose les données dans le dossier « Mon Cap » de votre Drive.
3L’app afficheSur le téléphone, l’app récupère les données à chaque ouverture, et partage les coches entre les téléphones de la famille.

Ce que Mon Cap lit

  • Coba : les travaux et évaluations, l’agenda des quatre prochains mois avec le jour du cycle, l’horaire, les activités, les commentaires des profs et les courriels de l’école.
  • Classroom : les travaux, consignes et pièces jointes de chaque cours, et les annonces des profs, que seuls les résumés par courriel contiennent.
  • L’aide à la lecture, si l’ordinateur le permet : l’IA de Chrome repère dans les messages les récupérations, sorties, changements et évaluations. Elle tourne sur l’ordinateur.

Mon Cap croise ces sources : une évaluation annoncée sur Classroom complète celle de Coba, ou apparaît avec la mention « Annoncé sur Classroom » si Coba ne l’a pas encore.

Les collectes

  • Automatiques toutes les 3 heures, tant que Chrome est ouvert sur l’ordinateur. Une collecte attend un moment où vous n’utilisez pas l’ordinateur, pour ne pas vous gêner. La fréquence se règle dans Réglages → Les collectes.
  • À la demande : bouton « Lancer une collecte », dans la fenêtre de l’icône ou les Réglages. Une demande manuelle passe devant une collecte automatique en attente.
  • En deux temps : les données sont déposées dans Drive dès que Coba et Classroom sont lus, puis complétées une fois que l’IA a lu les messages.
  • Prudentes : une collecte ratée ou incomplète ne remplace jamais de bonnes données. Un cours Classroom illisible ou un agenda tronqué est complété par la collecte précédente, et le journal le signale.

Les téléphones

  • Relier un téléphone : Réglages → Les téléphones, puis visez le QR code avec l’appareil photo. Sur iPhone, l’app guide l’installation en trois gestes : Copier mon code, Sur l’écran d’accueil, Coller mon code.
  • Les coches sont partagées entre tous les téléphones reliés, y compris les ajouts faits à la main.
  • Se mettre à jour : l’app se synchronise à l’ouverture, chaque minute, et quand on tire l’écran vers le bas.
  • Téléphone perdu : dans votre feuille Mon Cap, menu Mon Cap → Changer la clé des téléphones. Les anciens liens cessent aussitôt de fonctionner. Reliez ensuite le nouveau code dans les Réglages, et rescannez le QR code avec les téléphones de la famille.
  • Quel relais ? En bas de l’onglet Jour, l’app affiche le nom de son relais (« relais …xxxxxx ») ; les Réglages de l’extension affichent le même. S’ils diffèrent, téléphone et ordinateur n’écrivent pas dans le même Drive.
  • Ne partagez jamais le lien ou le QR code des téléphones, ni votre code de liaison : ils donnent accès aux données de votre enfant. Pour faire découvrir Mon Cap, envoyez la page d’installation.

Plusieurs ordinateurs

Installez l’extension sur le second ordinateur et suivez l’assistant, sauf à l’étape Google Drive : ne recopiez pas la feuille. Dans votre feuille existante, menu Mon Cap → 2. Obtenir mon code de liaison, avec l’adresse du déploiement actuel, puis collez ce code. Les deux ordinateurs collectent sans se gêner : une seule collecte a lieu à la fois, et aucune n’écrase un dépôt plus récent.

Mises à jour

L’extension vérifie chaque jour s’il existe une nouvelle version ; son icône affiche alors MAJ. On peut aussi vérifier tout de suite : menu Plus → Vérifier les mises à jour. Pour installer : téléchargez le zip, décompressez-le dans le même dossier en remplaçant les fichiers, puis rechargez l’extension (↻ dans chrome://extensions). Ce qui change à chaque version est décrit dans les nouveautés.

Questions

L’ordinateur doit-il rester allumé ?

Les collectes se font quand Chrome est ouvert. Si l’ordinateur dort, l’app garde les dernières données, et la collecte reprend au réveil.

Pourquoi des courriels de l’école n’apparaissent pas dans l’app ?

L’app est faite pour l’élève : les messages destinés aux parents, le suivi personnalisé et les invitations sont volontairement écartés. Vous les retrouvez dans Coba.

Les annonces des profs arrivent en retard

Elles viennent des résumés Classroom envoyés aux tuteurs. Réglez leur fréquence sur « quotidien », depuis le lien en bas d’un résumé.

Comment tout retirer ?

Supprimez l’extension dans chrome://extensions, puis, dans votre Drive, la feuille Mon Cap et le dossier « Mon Cap ». Sur les téléphones, supprimez l’icône de l’app.
